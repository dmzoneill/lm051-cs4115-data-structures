# CS4115 Data Structures

C++ work for the CS4115 Data Structures and Algorithm Analysis module,
from the LM051 Computer Systems degree at the University of Limerick.

## Contents

- Merge sort.
- A binary search tree with an iterator, including adding, finding and
  removing keys.
- Weekly lab exercises in `week2` and `week13`, and more code in
  `src`.

## Tech

- C++ (Eclipse CDT project)

## Building

Import the project into Eclipse CDT, or compile the files with `g++`.
